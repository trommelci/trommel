# SMAP v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the canonical-JSON map with the SMAP binary container of ADR-0009: a codec first, then the cut-over of the CLI and the workflow.

**Architecture:** SMAP v0 is a serialization of today's `TrommelMap`. `encodeSmap` writes a header, a section table, eight sections and a SHA-256 trailer; `decodeSmap` returns the same `TrommelMap` plus a `Graph` built straight from the adjacency section. The builder, the node model and the planner's rules do not change, and the JSON map stays as the test oracle.

**Tech Stack:** TypeScript on Node 22.18 or later, run through type stripping. `DataView`, `node:crypto`, Vitest 5.1, fast-check 4.10. No new dependency.

**Spec:** [docs/superpowers/specs/2026-11-14-smap-v0-design.md](../specs/2026-11-14-smap-v0-design.md). Its §5 is the byte layout; read it before any task.

## Global Constraints

- Zero runtime dependencies in `packages/core` and `packages/cli`. `npm run check:deps` must stay clean.
- Node 22 APIs only (`@types/node` 22). No `Uint8Array.prototype.toHex` or `fromHex`.
- `erasableSyntaxOnly`: no enums, namespaces or constructor parameter properties. Relative imports end in `.ts`; types use `import type`.
- Every multi-byte integer is little-endian through `DataView`, built with the array's `byteOffset` and `byteLength`. No typed-array view is laid over file bytes.
- The decoder throws `MapError` (from `packages/core/src/graph/map.ts`) and nothing else. The encoder throws `SmapEncodeError`.
- Strings sort by UTF-16 code unit: `a < b ? -1 : a > b ? 1 : 0`.
- The engine id stays `trommel-static-3`. The pinned JSON hash in `golden.test.ts` (`d648c838…806811`) must not move.
- Tests first. After each test file passes, mutate the code by hand to prove the tests can fail, and note the mutants for DECISIONS 33.
- Commits are small, conventional and signed off: `git commit -s`, ending with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.
- Ask Ojas before the first push, and before any merge. Never force-push.
- Run one test file with `npm test -- <path>`; the whole suite with `npm test`. Also `npm run lint`, `npm run typecheck`, `npm run check:deps`.

## Review Focus

1. **A file read with `readFileSync`** is a `Buffer` that may sit at a non-zero `byteOffset` in a shared pool. Decoding it must give the same map as decoding a fresh `Uint8Array`. (Task 2 and Task 5)
2. **A stale or foreign file where a map is expected:** JSON text, an empty file, a file shorter than the header. Each is a `MapError` that says it is not a SMAP file, and the plan runs everything. (Task 3 and Task 8)
3. **An empty repository:** no entries, no nodes, no edges, no tests. It encodes and decodes to itself. (Task 5)
4. **Awkward strings** in keys, patterns and causes: a leading U+FEFF, a NUL, an unpaired surrogate, and byte lengths of 127, 128, 16,383 and 16,384. Each round-trips exactly. (Task 2)
5. **A cache directory that holds both `map.json` and `map.smap`,** and a SMAP built by another engine. The plan reads only `map.smap`, and names the engine mismatch as the cause. (Task 8)

```ts
export class SmapEncodeError extends Error {}
export class ByteWriter {
  u8(value: number): void; u16(value: number): void; u32(value: number): void;
  varint(value: number): void;            // SmapEncodeError unless an integer in [0, 2^32)
  bytes(bytes: Uint8Array): void;
  str(text: string): void;                // varint byte length, then encodeString(text)
  hex(hex: string, length: number): void; // SmapEncodeError unless 2 × length lowercase hex digits
  readonly length: number;
  finish(): Uint8Array;                   // a copy of exactly the bytes written
}
export class ByteReader {
  constructor(bytes: Uint8Array, what: string); // `what` starts every MapError message
  u8(): number; u16(): number; u32(): number;
  varint(): number;                       // MapError on a padded form or a value ≥ 2^32
  count(minBytesEach: number): number;    // a varint; MapError when count × minBytesEach > remaining
  bytes(length: number): Uint8Array;      // a view, not a copy
  str(): string; hex(length: number): string;
  readonly remaining: number;
  end(): void;                            // MapError unless remaining is 0
}
export function encodeString(text: string): Uint8Array;  // UTF-8; an unpaired surrogate as 3 bytes
export function decodeString(bytes: Uint8Array, what: string): string; // MapError unless canonical
export class FrontWriter { write(out: ByteWriter, text: string): void }
export class FrontReader { read(input: ByteReader): string } // MapError unless the shared count is maximal
export function compareStrings(a: string, b: string): number;
```
